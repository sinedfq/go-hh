# OTP, вход и общий стиль — сборка 14

- Сервер генерирует ровно четыре ASCII-цифры, включая ведущие нули. Проверка,
  уведомления Android и оба клиента используют этот формат. Сохраняются срок
  действия, лимит пяти попыток, ограничения отправки и привязка к устройству.
- Цифры появляются отдельно. Во время проверки синяя точка перемещается между
  четырьмя блоками; зелёное подтверждение показывается только после ответа сервера.
  Android оставляет подтверждение на экране перед переходом. При выключенных
  системных анимациях точка статична; фоновый экран не запускает её анимацию.
- Android подставляет полученный Firebase-код только для текущего запроса,
  совпадающего номера и неистёкшего срока. Автоматической отправки формы нет.
  SMS читать не требуется. Код не сохраняется на диск и не пишется в журнал.
  В браузере включён `autocomplete=one-time-code`; фактическая подстановка зависит
  от браузера и способа доставки. Уведомление на другом устройстве не читается сайтом.
- Кнопка создания аккаунта выделена. Обычный экран входа стал компактнее, индикатор
  отправки кода центрирован. Для клавиатуры, низких окон и увеличенного шрифта
  сохранена прокрутка вместо обрезания элементов.
- Веб использует цвета Android, скругления карточек и кнопок, общий вид заголовков.
  На широком экране навигация остаётся слева в отдельной стеклянной панели;
  на планшете она сужается, на узком телефоне сохраняется мобильная навигация.
- Стартовая анимация ждёт запросов текущего экрана, шрифтов и его изображений.
  Веб ждёт декодирования и отрисовки видимых изображений, Android — завершения
  загрузки Compose-изображений. Ошибки изображений разрешают обычную заглушку.
  Не загружаем все страницы бесконечной ленты: следующие вакансии остаются ленивыми.
  Для внешних картинок/шрифтов веба есть предел ожидания 8 секунд.
- Убран повторный запрос списка вакансий на вебе при формировании списка городов.

После обновления нужно перезапустить API и веб-контейнеры, если используются они:
`docker compose up -d --build`. При запуске без Docker перезапустите API своим
`./scripts/api.ps1 -RequirePush`, а веб — `npm run dev` в `frontend`.
Старые шестизначные коды требуется запросить заново после обновления сервера.
Старые APK с шестизначным вводом нужно обновить до этой сборки.

Измерения FPS в этой доработке не проводились; улучшение FPS не заявляется.

Проверено: 52 JVM-теста Android, 20 тестов веба, сборки обоих клиентов и
серверные тесты. Интеграции с PostgreSQL проходят в GitHub CI. Два Android
UI-теста прошли: ограничение ввода с ведущим нулём, состояние подтверждения и
видимость действий входа. Эмулятор периодически показывает ANR своего System UI;
проверка на физическом телефоне всё ещё полезна. Интерактивный браузер в этой
сессии не подключён, поэтому визуальная проверка веба ограничена сборкой и кодом.
