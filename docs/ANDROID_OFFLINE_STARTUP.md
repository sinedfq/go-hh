# Android: сохранённый сеанс и стартовая загрузка

При временной ошибке сети или ответе 5xx приложение использует последний
успешный JSON-ответ. Это позволяет восстановить профиль по `/api/me`,
сохранить вход и читать ранее загруженные вакансии, отклики и другие разделы.
Над интерфейсом появляется пометка «Сохранённые данные».
Подтверждённый сервером 401 защищённого API завершает сеанс. Неверный пароль
или OTP и поздний ответ от предыдущего токена не сбрасывают новый сеанс.

Ключ кэша включает полный URL, сервер и отпечаток токена. Токен не записывается
в файлы ответов. JSON хранится в приватной директории без резервного копирования,
до 48 МБ и не дольше семи дней. Выход, смена сервера и подтверждённое истечение
сеанса очищают ответы; поздний запрос не может записать старые данные после очистки.
Без ранее сохранённых данных первый вход всё ещё требует доступного сервера.

OTP, авторизация, typing, unread-count, PDF и изменяющие запросы не воспроизводятся
из кэша. Отправка сообщения, отклик и другие изменения требуют сети.
При обычной работе чтение сначала обращается к серверу, при ошибке использует
снимок. Только результаты предзагрузки можно один раз переиспользовать в течение
минуты. Обновление свайпом и успешные изменения сбрасывают это переиспользование.

Перед созданием основных экранов InitialDataViewModel ожидает профиль, ленту,
истории, отклики, список чатов, справочники, сохранённые поиски, резюме/статистику
или данные работодателя. Для соискателя заранее читаются страницы каталога:
до 1000 вакансий. Этот каталог сразу передаётся VacanciesViewModel, поэтому
его уже загруженные страницы не запрашиваются при прокрутке.
У более крупных каталогов, новых фильтров и дополнительных постов сохраняется
пагинация. Истории сохраняют существующую проверку срока 24 часа.

После данных ожидается предзагрузка до 256 уникальных изображений — логотипов,
аватарок и фотографий публикаций/историй, включая невидимые элементы списков.
Одновременно загружаются до четырёх групп данных и трёх изображений. Изображения
используют общий Coil disk cache 96 МБ и ограниченный memory cache.
В офлайн-режиме предзагрузка картинок читает только существующий disk cache.
Неполученные изображения остаются с заглушкой. Полные видео и новые страницы
комментариев/сообщений не скачиваются на старте; видео-превью сохраняют прежний механизм.

Проверки: OfflineReadsTest проверяет перезапуск хранилища, отсутствие сети,
5xx против 401, разделение аккаунтов/серверов, границы размера/срока,
инвалидацию, одноразовое переиспользование и исключение OTP/изменений.
OfflineSessionTest проверяет сохранение токена при сетевой ошибке и гонку 401.
InitialDataReadinessTest удерживает ответ изображения после двух страниц вакансий
и проверяет, что загрузка ещё не завершена. Эти Android-тесты используют MockWebServer,
не останавливая настоящий сервер и не создавая реальные аккаунты.
