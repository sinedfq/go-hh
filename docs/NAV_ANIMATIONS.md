# Анимации нижней навигации Trudomix

Выбор добавлен в существующий экран **Настройки → Оформление → Анимация нижней навигации**.
В текущем проекте экран персонализации называется «Оформление»; его название и маршрут
`settings/appearance` сохранены. Новые маршруты не добавлялись.

| Вариант | Поведение |
| --- | --- |
| Мягкая волна | Заливка перемещается с плавным ускорением/замедлением; верхняя граница слегка поднимается над выбранной секцией. По умолчанию. |
| Упругая волна | Контролируемая spring-анимация положения и верхнего изгиба; заливка растягивается в направлении движения. |
| Раскрытие из центра | Окружность служит маской заполнения: раскрывается до дальних углов секции, затем заменяется полной прямоугольной заливкой. Предыдущее выделение затухает. Внешний контур неподвижен. |
| Без анимации | Новая секция заполняется сразу, переход цвета подписи и иконки также мгновенный. |

Сохранены пять вкладок, их порядок, подписи, иконки, увеличенная центральная кнопка,
веса секций (1 / 1 / 1,15 / 1 / 1), размеры, отступы, существующие цвета и обработчики
нажатий. Нижняя граница неподвижна. Голубая заливка взята из существующей палитры;
новых разделителей, голубых обводок или отдельных выделяющих капсул нет.
Существующий фон и светлая граница панели следуют её контуру.

Настройка `nav_animation_style` хранится в **существующем DataStore `theme_prefs`**
рядом с `app_theme_mode`. Значения: `smooth`, `elastic`, `center_reveal`, `none`.
Неизвестное или отсутствующее значение означает `smooth`. Основная панель и пример
используют один GlassNavigation. Пример меняет только свою локальную вкладку и
не запускает навигацию, запросы или экраны приложения.

NavHighlightState содержит только состояние выделения и конечные Animatable.
Маршрутизация остаётся в прежних обработчиках. Новое нажатие отменяет текущий
переход и продолжает его с текущего положения. При радиальном раскрытии сохраняются
видимые частичные раскрытия; число затухающих слоёв ограничено восемью.
После завершения перехода новые кадры не запрашиваются. В фоне переход отменяется
и фиксируется в конечном состоянии. При animator_duration_scale = 0 переключение
мгновенное; остальные системные коэффициенты обрабатываются штатным Animation API.

Геометрия секций, Path, дуги, кисти и Stroke кэшируются в drawWithCache. Значения
анимации читаются только в draw-фазе. Нет blur, RenderEffect, новых библиотек,
бесконечных анимаций выделения или изменения размеров layout при переходе.
FPS и улучшение производительности для этих изменений не заявляются: новое
профилирование на физическом устройстве не проводилось.

## Изменённые файлы

- `data/local/NavAnimationStyle.kt` — типизированные варианты и значение по умолчанию.
- `data/local/ThemeManager.kt` — чтение и запись ключа в существующем DataStore.
- `ui/components/NavHighlight.kt` — конечные переходы и отрисовка общей заливки.
- `ui/components/GlassNavigation.kt` — подключение выделения к существующей панели.
- `ui/screens/profile/ProfileViewModel.kt` — состояние и сохранение настройки.
- `ui/screens/settings/NavAnimationPicker.kt` — выбор четырёх вариантов и общий интерактивный пример.
- `ui/screens/settings/AppearanceScreen.kt` — подключение новой секции настроек.
- `src/test/.../NavGeometryTest.kt` — геометрия секций, радиус и значения настройки.
- `src/androidTest/.../NavAnimationTest.kt` — переходы, быстрые нажатия, полная заливка, фон, системное отключение анимаций и сохранение через перезапуск процесса.
- `src/androidTest/.../NavAnimationPickerTest.kt` — выбор каждого варианта и интерактивность общего примера с прежними вкладками.

Пути Kotlin указаны относительно `android/app/src/main/java/com/example/trudomix`,
кроме явно обозначенных тестов.
