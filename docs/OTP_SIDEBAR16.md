# OTP и сворачиваемая стеклянная навигация — сборка 16

## Причины ошибок OTP

- В PowerShell одиночный результат `if` превращал массив `--all` в строку;
  splatting передавал её посимвольно. Теперь используется типизированный `string[]`.
  Проверка реального скрипта с подменённым Go охватывает `-All` и `-Phone` без записи в БД:
  `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/tests/otp-reset-arguments.ps1`.
- На порту 8080 продолжал работать `.cache/trudomix-api-build10.exe`. Он выдавал
  старые шестизначные коды, а новый Android-клиент принимал четыре цифры.
  Этот процесс заменён новой сборкой с Firebase. Конфигурация OTP теперь возвращает
  `code_length`; Android сообщает об устаревшем сервере до отправки запроса.
- Сервер возвращал 60 секунд и для минутной паузы, и для часового лимита.
  Теперь Retry-After вычисляется по настоящему окну ограничения; веб и Android
  учитывают его. Лимиты не отключены.

`./scripts/otp-reset.ps1 -All` уже успешно выполнен: инвалидированы 6 старых запросов.
Сброс удаляет только OTP challenges/receipts, сохраняя аккаунты и привязки номеров.
Для конкретного номера используйте `-Phone '+7…'`. Общий сброс разрешён в development.

`./scripts/api.ps1 -RequirePush -Restart` сначала собирает API, затем останавливает
старый процесс только из текущего рабочего каталога и запускает новый. Без -Restart
скрипт сообщает о несовместимом OTP API вместо молчаливого использования старой версии.

Android различает принятие запроса Firebase и получение кода устройством. Если код
не получен за 12 секунд, появляется пояснение. Полученный код можно снова показать
в уведомлении без нового запроса. Код остаётся только в памяти, не попадает в логи.

## Веб

На десктопе панель слева имеет ширину 76 px, показывая иконки и логотип. При наведении
или фокусе с клавиатуры раскрывается до 244 px: появляются подписи и название.
Она раскрывается поверх страницы, не меняя ширину контента. Цвета, прозрачность,
тонкие границы и подсветка согласованы с мобильной палитрой. Blur используется
для панели, а не для каждой карточки. Кнопки навигации теперь нативные button,
доступные с клавиатуры. При отключённых анимациях переходы сокращаются системным CSS.
На узком экране сохраняется мобильная навигация.
