# Общая навигация сайта и Android

Сайт использует нижнюю стеклянную капсулу на всех размерах экрана.
Для соискателя: Главная, Свайпы, Поиск, Отклики, Чаты.
Для работодателя: Главная, Компания, Вакансии, Отклики, Чаты.
Центральная кнопка увеличена, фон поиска содержит статичные точки.

Кнопка «Ещё» рядом с капсулой открывает остальные разделы и аккаунт.
Меню — нативный модальный dialog с удержанием фокуса, Escape и возвратом
фокуса на кнопку. Существующие обработчики экранов и чатов сохранены.
Счётчик непрочитанных перенесён из плавающей кнопки в вкладку чатов,
второго опроса сервера нет. Гостевые разделы с авторизацией открывают вход.
Отступ снизу позволяет прокрутить содержимое выше панели.

Цвета берутся из существующей темы. На узких экранах подписи уменьшены,
в коротком горизонтальном окне скрыты; учитывается safe area.
Есть варианты без прозрачности и переходов для системных настроек.

Проверки: 21 веб-тест, lint (существующие предупреждения), production build.
Образ frontend пересобран и запущен; проверено наличие нового CSS через
localhost:3000. Подключённого браузера для визуальной проверки нет.

Запуск всего Docker-стека: `scripts/stack.ps1`. Сайт — localhost:3000,
API — localhost:8081, PostgreSQL — localhost:5432, Firebase работает
в сервисе notifications. Миграции и uploads-init завершаются после подготовки.
Android работает в эмуляторе, отдельного контейнера для него нет.
Эмулятор обращается к контейнерному API через http://10.0.2.2:8081/;
локальный API для телефона запускается через `scripts/api.ps1 -RequirePush`.
