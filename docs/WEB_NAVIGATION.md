# Нижняя навигация сайта

Веб-версия использует собственную широкую стеклянную панель снизу.
Все доступные роли разделы находятся прямо в панели, без меню «Ещё».
Пункты имеют иконки и постоянные подписи, объединены в группы с тонкими
разделителями. Активный экран выделен акцентным фоном и короткой полоской.
Крупная круглая Android-кнопка заменена обычным пунктом поиска с цветной иконкой.

Соискателю доступны: Главная, Поиск, Карта, Свайпы, Избранное, Мои поиски,
Рекомендации, Компании, Мои отклики, Чаты, Профиль и Выйти.
Работодателю: Главная, Карта, Компания, Вакансии, Создать, Отклики,
Аналитика, Чаты, Профиль и Выйти. Администратор видит оба набора.
Гостевые действия, требующие аккаунта, открывают существующую форму входа.

На широком экране панель занимает ширину своего содержимого и центрируется.
При нехватке места остаётся один ряд с горизонтальной прокруткой и стрелками.
Переход из другого места сайта прокручивает выбранный пункт в видимую область.
Клавиатурный фокус, счётчик чатов и существующие обработчики переходов сохранены.
Стекло и подсветка используют текущую тему и цвет интерфейса. Учитываются safe area,
низкие окна, reduced motion и reduced transparency. Android не изменён.

Проверки: 21 веб-тест, lint с существующими предупреждениями, production build.
Для локального обновления: docker compose build frontend, затем
 docker compose up -d --no-deps frontend. API и данные при этом не меняются.
Подключённого браузера для визуальной проверки нет.
