# Нижняя навигация сайта

Панель показывает шесть основных направлений. На широком экране иконки
и подписи стоят в строку; высота самой кнопки 46 px. Нет дублирующего
логотипа, разделителей, стрелок прокрутки и постоянно видимой кнопки выхода.
Подсветка активного направления использует текущий акцент интерфейса.

Для соискателя: Главная, Поиск, Обзор, Отклики, Чаты, Личное.
«Обзор» содержит карту, свайпы, рекомендации и компании. «Личное» — профиль,
избранное, сохранённые поиски и выход. Для работодателя: Главная, Вакансии,
Компания, Отклики, Чаты, Личное. Группа вакансий содержит список, создание,
аналитику и карту. Администратору сохранены также кандидатские разделы.
Все предыдущие функции доступны через эти группы.

Группы открываются по клику в небольшом dialog с двумя колонками.
Есть Escape, закрытие по фону, удержание фокуса и возврат фокуса на кнопку.
Активность группы определяется по текущему экрану. Вход гостей, существующие
обработчики переходов и счётчик чатов сохранены. Нового опроса сервера нет.

На узких экранах подписи находятся под иконками, все шесть направлений
помещаются без горизонтальной прокрутки. Учитываются safe area, короткие
окна, reduced motion и reduced transparency. Android не изменён.

Проверки: 21 веб-тест, lint с существующими предупреждениями, production build.
Локальное обновление: docker compose build frontend, затем
 docker compose up -d --no-deps frontend. Подключённого браузера для визуальной
проверки нет.
