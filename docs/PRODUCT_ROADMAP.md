# Следующие этапы Trudomix

Выбраны все восемь направлений. Выполняются по порядку, отдельными проверяемыми этапами.

1. Подбор с объяснениями: реальные совпадения навыков, города, опыта и формата;
   сохранённая кнопка «Не интересно», возможность вернуть скрытые.
   Первый этап добавляет этот функционал на вебе и в мобильной главной.
2. Календарь собеседований: встречи, переносы, напоминания и связь с откликами/чатами.
3. Помощник резюме: подсказки по опыту, формулировкам и портфолио.
4. Командный найм: рекрутеры, роли, внутренние заметки, ответственные.
5. Проверка компаний и модерация: жалобы, проверка сведений, дубли и спам.
6. Стабильность: измерения скорости на устройствах, мониторинг ошибок, медленная сеть.
7. Продвижение вакансий: явная отметка продвижения, бюджет и статистика.
8. Подписка компаний: командные инструменты, автоматизация, подробная аналитика.

Пункты 2–8 — следующие этапы, не часть первой поставки. Для реальных платежей
понадобятся оператор сервиса и конфигурация платёжного провайдера; цены и списания
не задаются без этих данных.

Дополнение первой поставки: логотип компании в списке чатов и шапке переписки
соискателя, фото кандидата со стороны работодателя. Аватарки авторов сообщений
сохраняются отдельно. API возвращает company_logo и candidate_photo; старые клиенты
игнорируют дополнительные поля, новый клиент поддерживает старые ответы с заглушкой.
