# Загрузчики из HTML

Актуальное уточнение: искусственная задержка появления 200 мс отменена на обеих
платформах. Обычные индикаторы отображаются сразу; мини-логотип использует тот же
контур и градиенты, что большая заставка. Цикл Android — 3,7 с, веба — 9,6 с,
без добавленной паузы. Параметры задержки в историческом описании ниже отменены.

Обновление: в Android доступны три стиля из `icons/trudomix_three_loading_styles.html`:
«Контур + импульс», «Неоновая сборка», «Световые створки». Выбор и предпросмотр —
в настройках, сохранение — локально на устройстве. Новый цикл Android занимает
до 3,9 с с задержкой появления 200 мс, далее ожидает API. Веб сохраняет
последовательность ниже. При обновлении свайпом Android показывает текущую
иконку приложения с учётом темы. Смена темы веба использует круговую View Transition
от центра кнопки; при reduced motion или отсутствии API тема меняется сразу.

Актуальная реализация от 26 октября 2026 года. Источник —
`icons/trudomix_slot_impact_glow.html` (демонстрационные кнопки в приложение не переносились).

Стартовый экран веба и Android использует исходный контур буквы, градиенты
светлой/тёмной темы и фиолетовый шар. Последовательность: прорисовка буквы,
заливка, прорисовка и заливка шара, название, эффект установки с мягким
изменением масштаба, вспышкой и расширяющимся кольцом. Веб рисует SVG/Canvas,
Android — Compose Canvas без WebView и дополнительных библиотек.

Исходная последовательность занимает 9,6 с, перед появлением добавлены 200 мс.
После 9,8 с остаётся статичный логотип до завершения начальной загрузки API.
При отключённых системных анимациях сразу показывается финальный кадр.
При ошибке подключения остаются логотип и кнопка повтора; повтор не запускает
длинную анимацию заново. Запросы и существующие тайм-ауты не задерживаются.

Для загрузок внутри экранов и кнопок используется компактный `AppLoader`
из кнопки повтора подключения: знак внутри вращающегося кольца. Он появляется
через 200 мс после монтирования; при быстром завершении операции индикатор
не успевает появиться. Место резервируется сразу, блокировка занятой кнопки
включается немедленно. На вебе задержка задаётся CSS, в Compose — отменяемой
`LaunchedEffect` с `delay`. Задержка не увеличивает время запросов.

Индикаторы с известным прогрессом (время истории, заполненность резюме)
сохранены. Неопределённые линейные загрузчики в разделах Android заменены
общим `InlineLoadingState`. Фоны индикаторов прозрачные.

Основные файлы:

- `frontend/index.html`, `frontend/public/splash.js`, `frontend/public/splash.css`;
- `frontend/src/components/common/AppLoader.jsx`, `PageLoader.css`,
  `CompactRefreshButton.jsx`, `NetworkErrorState.jsx`;
- `android/app/src/main/java/com/example/trudomix/ui/loading/SlotLoader.kt`,
  `SlotMarkPath.kt`, `SplashTiming.kt`, `TrudomixSplash.kt`, `AppLoader.kt`,
  `NetworkErrorState.kt`.

Файл `SlotMarkPath.kt` содержит контур, извлечённый из исходного HTML,
без упрощения геометрии. Иконки launcher, API, авторизация и навигация
этой доработкой не меняются.
