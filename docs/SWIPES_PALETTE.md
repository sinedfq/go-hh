# Свайпы и палитра интерфейса

Последние анимации выделения нижней панели отменены: PR #17 закрыт без слияния,
неопубликованный черновик APK №12 удалён. Эта версия основана на прежней панели
из dev/build 11. Сохранены её кнопки, расположение и прежние оптимизации.

## Свайпы

- Карточка в общем стиле: логотип и название компании, IT-значок, должность,
  зарплата, город, опыт, формат работы, навыки и краткое описание.
- Есть переход к полной вакансии. На низких экранах и при крупном шрифте
  содержимое доступно через прокрутку.
- Вправо — сохранить в избранное, влево — пропустить. Короткий жест плавно
  возвращает карточку. Те же действия доступны кнопками.
- Прогресс просмотра и число сохранений показаны отдельно.
- Можно вернуть последнее решение. Если действие добавило вакансию в избранное,
  отмена убирает именно это добавление; вакансии, уже бывшие в избранном при
  загрузке подборки, не удаляются.
- Следующая страница подгружается, когда остаются три карточки. Загрузка страницы
  не блокирует действия с уже показанными карточками.
- Ошибка сохранения оставляет карточку доступной; она возвращается на экран.
  Ошибка загрузки позволяет повторить загрузку. Отмена имеет только один шаг.

Функции используют существующие API поиска и избранного. Новых серверных
маршрутов нет. Запросы ограничены начальной загрузкой, страницами и действиями
пользователя; периодический polling не добавлялся. Декоративные подсказки жестов
читают смещение в graphicsLayer, а не перестраивают экран на каждом кадре.

## Цвет

`Настройки → Оформление → Цвет интерфейса → Открыть палитру`.

Есть прежние шесть оттенков в виде цветных образцов и произвольный цвет:
поле насыщенности/яркости, радужная шкала оттенка, доступные ползунки и HEX.
Изменения в диалоге локальны до нажатия «Применить». «Отмена» сохраняет текущий
цвет приложения. Сам интерфейс не перекрашивается при каждом перемещении пальца.

Свой цвет хранится в существующем `theme_cache`, ключ `custom_accent`; прежний
выбор пресетов `accent` сохраняется. Выбор пресета отключает свой цвет. Настройки
восстанавливаются при запуске. Оттенок адаптируется к светлой/тёмной подложке для
контраста, цвет надписей на акценте подбирается автоматически. Логотипы не меняются.
