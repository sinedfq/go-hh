ТРУДОМИКС — АНИМАЦИИ ЗАГРУЗКИ

web/index.html — рабочее интерактивное превью. Откройте через локальный HTTP-сервер, например:
  cd web
  python -m http.server 8081
  затем http://localhost:8081

web/icons — 9 выбранных логотипов в 9 вариантах цвета (256x256 PNG), извлечены из ранее подготовленного пакета.
android/TrudomixLoadingScreen.kt — пример Jetpack Compose с выбранным ресурсом и темой.

ИНТЕГРАЦИЯ:
Web: подключить компонент в существующий React/Vue/HTML-проект, получать выбранный логотип и тему из настроек приложения; не копировать демонстрационный localStorage поверх реального хранилища.
Android: импортировать выбранные иконки в res/drawable-nodpi, передать drawable resource ID из сохранённых настроек и текущую тему; закрывать загрузку по фактической готовности.

Для Web: анимация учитывает prefers-reduced-motion. Для Android: при внедрении учтите системную настройку уменьшения анимации.
Это демонстрация и шаблон интеграции, не готовый патч к исходникам двух проектов.
